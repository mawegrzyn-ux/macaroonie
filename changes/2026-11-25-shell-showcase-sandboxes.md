# macaroonie.com: try the kitchen flow and the kiosk designer

- Try it on macaroonie.com now has two sandboxes you can use in your browser, with nothing to sign up for and nothing saved or sent.
- Set up a kitchen: start from a grill, a fryer, a bar, a Sleeper that holds desserts, the pass and a ticket printer. Add stations, a Splitter, a Sleeper or a printer, tap a box's arrow and then another box to link them, and choose which dishes each link takes. Send a test order (2 burgers, fries, a cola and a brownie) and watch it travel: each kitchen screen shows its ticket, the printer prints, the Sleeper holds the brownie until you press Fire now, and Done and Ready move the order on. It runs the same kitchen rules as the kitchen screens' test bench.
- Design a kiosk: pick a brand colour, heading and body fonts, text sizes and a logo word, rename and reprice four dishes, and tap through the kiosk as a guest: welcome, eat in or take away, the menu, a dish with a size, the order and the order number. It uses the kiosk's own fonts, text sizes and words.
- The home page and Try it link straight to both; each ends with "Like what you see? Register interest".
