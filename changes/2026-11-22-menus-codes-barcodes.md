# Product codes and barcodes, and scanning at the till

- A dish's panel has Codes: a product code and a barcode, both optional. A barcode with a wrong last digit shows in red, and each code can be used once in a menu.
- Retail goods can have codes for each option, so a T-shirt's sizes each have their own barcode.
- With a barcode scanner plugged into the till, scanning an item on an open check adds it, with its size or colour when the code belongs to one.
