# What each of Pepper's requests to the AI model costs, by model

- Every request Pepper makes to the AI model (a step of a chat, a menu search, reading an invoice, a receipt or a menu, the report smart builder, local info, the theme maker, translations, a new location) is now kept for 90 days: when, what for, which model answered, its tokens, how long it took and an estimated cost in dollars at the model's list prices.
- Reports has a new subject, **Pepper's model requests** (View on Pepper), and a starter, **Pepper's cost by model**: requests, tokens in and out a request, the cost, the cost of one request and the average time, by model; tap a model to see what the requests were for. Who asked isn't in it.
- Migration 271 (`ai_requests`).
