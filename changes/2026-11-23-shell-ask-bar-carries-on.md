# The ask bar carries on the chat you had open with Pepper

- Asking Pepper from the ask bar (Enter, Ask, the Ask Pepper row or a suggestion under the bar) now adds the question to the chat you last had open, as the phone's Pepper page already did, instead of starting a new chat. With no chat open it starts one; the plus at the top of Pepper's panel still starts a fresh one.
- A second question while Pepper is still answering waits for the answer, then sends.
- No migration.
