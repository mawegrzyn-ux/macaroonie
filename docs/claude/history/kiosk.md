# Self-order kiosks: what shipped

Completed work in this area, oldest first, as written at the time. Reference only: for how things work now read `docs/claude/areas/kiosk.md` and the code. A later entry can supersede an earlier one.

New entries: a few lines each (what shipped, the migration number, the date, where the code is). No test tallies.

- ✅ **Self-order kiosks** *(migration 172)* — the user's brief (17 Oct 2026): a fully fledged kiosk PWA modelled on the Wingstop screenshots, with choices shown as a grid, a list, a slider (heat scale) or a spin wheel. A kiosk is a till device (`kind = 'kiosk'`) whose orders are counter checks made of till events (`kioskOrder()`), so they reach the Counter list, the kitchen flow, Till reports (kiosk named) and Cash Recon unchanged; the kiosk rules allow only its own counter orders, menu dishes, automatic offers and `card_external` payments (test reader for now). App (`pos/src/kiosk`): start screen (media, languages, order types, allergens), menu (rail, home page with banners / featured tiles, dish cards, quick add), dish and combo builder (displays per group / step, level scale, the Add button pointing at what's missing, allergens of what's picked, a combo's allergens as the union of its dishes), basket with "Anything else?", name / table number, card or counter, order number, receipts, idle warning, reach, sold out live, offline pause, outbox for paid card orders (provisional number), counter retry without doubles; nine languages built in plus `menu_translations`. Designs: tenant-wide `kiosk_designs` edited at `/pos/kiosk-designs/:id` beside the real kiosk in a frame (postMessage), Save / Discard / leave confirm, colour sets and contrast warnings. Option groups: `kiosk_display`, scale words, option picture / words / level, drag order; combo steps: `display`, typed-in choice picture / words. Menus → Translations with an AI first draft. Media changes with Till setup manage. Also fixed: a new option group's options came back sorted by name (`sort_order` defaulted to 0). Tested: 102 shared unit tests, 52 API checks (two tenants: designs, preview links, a paired kiosk's config and rules, translations, media, report names), kiosk flows in Chromium at 810 x 1440 and 1440 x 810 (full order both ways, 40 + 15 checks: languages, combos, allergens, idle, declined card, offline, outbox, retry, sold out), 44 design editor checks (preview, save, discard, view only, 1015 / 390), 34 Menus checks (option group, combo step, translations), 11 AI suggestion checks against a stand-in Claude.
